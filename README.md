# 작은 하루 · 먼작귀 속의 나

현재 버전: **1.2.0**. 업데이트할 때 압축 안의 전체 파일과 폴더를 기존 저장소 최상위에 덮어써 주세요. 이번 버전에는 공유 처리를 위한 `sharing.js`가 추가되었습니다. 일부 파일만 덮어쓰지 말고 전체 파일을 갱신해 주세요.

이 버전에는 다음 변경이 들어 있습니다.

- 시작 시 이름/별명 등록(최대 12자), 브라우저 저장, 결과에서 이름 수정
- `'민구'님은 우사기 성격이에요!`처럼 이름을 넣은 결과와 PNG·JPG 카드
- 20명별 ‘친해질 때·일을 할 때·마음이 지칠 때’ 설명
- **링크 공유**: 이름·설명·이미지 없이 사이트 주소만 전달
- **카드 다운로드**: 이름·캐릭터·짧은 성격 설명이 담긴 PNG 또는 JPG를 선택해 저장. 카드 이미지에서 ‘나도 해보기’와 주소 제거
- **링크 공유 / 카드 공유**: 카카오톡·인스타그램·다른 앱을 고르는 선택창 표시, 지원 기기에서는 실제 앱 공유창으로 연결
- 공유를 취소하거나 지원하지 않는 브라우저에서도 자동으로 링크를 복사하지 않음. 복사·저장은 별도 버튼으로 선택
- 210개 캐릭터 조합(사용자/친구 방향을 구분하면 400가지 선택)의 궁합 문구와 활동 제안
- 캐릭터마다 잘 맞는 친구 2명, 조금 안 맞을 수 있는 친구 2명과 이유·팁
- 받침에 맞는 을/를·이/가·은/는·과/와·으로/로 선택
- 이미지 문항의 작은 정사각형 2×2 배치 유지

모바일 화면에 맞춘 먼작귀 팬 메이드 성격 테스트입니다. HTML, CSS, JavaScript만 사용하므로 빌드, 패키지 설치, 서버 API, API 키가 필요하지 않습니다. 캐릭터 이미지와 한글 폰트도 포함되어 있습니다.

## GitHub에 올리고 실행하기

1. ZIP을 압축 해제합니다. ZIP 자체가 아니라 **압축 안의 파일과 `assets`, `tests`, `docs` 폴더**를 저장소에 올립니다.
2. 저장소의 최상위에 `index.html`이 있도록 업로드합니다. 새 저장소라면 웹 화면의 `uploading an existing file`을 이용할 수 있습니다.
3. GitHub 저장소의 **Settings → Pages**를 엽니다.
4. **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**를 고르고 Save를 누릅니다. 기본 브랜치 이름이 다르면 해당 이름을 선택합니다.
5. 배포가 완료되면 Pages 화면에 표시되는 주소를 엽니다.

공식 설정 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

이미지·스크립트 경로는 상대 경로입니다. 공유 주소와 미리보기 메타 태그는 요청하신 **https://mkr-games.github.io/Chiikawatest/** 로 설정했습니다. 링크 공유는 이 주소만 보냅니다. 별도의 친구 초대에는 `?with=usagi`처럼 초대한 캐릭터가 붙습니다. 이름과 답변은 URL에 넣지 않습니다.

### 링크 미리보기 이미지 설정

현재 주소에 맞춰 설정을 마쳤습니다. 주소를 변경하면 `personalization.js`의 `SHARE_BASE`와 `index.html`의 `og:url`, `og:image`, `canonical`을 함께 바꿔 주세요. 정적 사이트이므로 메신저의 링크 미리보기는 공통 표지이며, 이름과 캐릭터가 담긴 이미지는 **카드 공유**로 나눕니다.

### 카카오톡·인스타그램 공유

**링크 공유**와 **카드 공유**를 누르면 사이트 안에서 **카카오톡 / 인스타그램 / 다른 앱** 선택창이 먼저 열립니다. 플랫폼을 고르면 지원되는 브라우저에서 휴대폰·컴퓨터의 기본 앱 공유창을 엽니다. 그 창에서 사용할 앱을 선택합니다. 웹페이지는 기본 공유창에서 특정 앱을 미리 선택하거나, 설치되지 않은 앱을 목록에 추가할 수 없습니다.

- 링크 공유: `https://mkr-games.github.io/Chiikawatest/` 주소만 전달합니다. 제목, 이름, 설명, 이미지가 추가되지 않습니다.
- 카드 공유: 이름·캐릭터·짧은 설명이 그려진 실제 이미지 파일을 전달합니다. 카카오톡·다른 앱 선택에서는 지원하면 설명과 테스트 URL도 함께 전달합니다.
- 인스타그램용 카드 공유: JPG 이미지 파일만 기본 공유창에 전달합니다. 게시글 설명이나 스토리 링크에 넣을 내용은 **공유 문구와 링크 복사**로 가져갈 수 있습니다. 웹페이지에서 스토리를 자동 작성하거나 게시하지 않습니다.
- 카드 다운로드: **PNG 다운로드 / JPG 다운로드** 중 선택합니다. 확장자와 실제 이미지 형식이 일치하며 둘 다 1080 × 1440입니다. 카드 이미지 안에는 ‘나도 해보기’나 사이트 URL이 표시되지 않습니다.
- 기본 공유를 지원하지 않거나 원하는 앱이 목록에 없을 때: 선택한 플랫폼에 맞춰 링크를 복사해 DM·채팅에 붙이거나, 카드를 저장해 사진으로 첨부하는 방법을 보여 줍니다. 공유 취소 시 자동 복사나 재시도를 하지 않습니다.

앱이 설치되어 있어도 운영체제·브라우저·앱이 받는 데이터 종류에 따라 기본 공유 목록에 나타나지 않을 수 있습니다. 현재 버전은 Web Share API를 사용하며 별도 카카오 SDK나 인스타그램 API 연동은 포함하지 않습니다. API 키, 로그인, 서버 업로드 없이 동작합니다.

공식 문서: https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share

## 내 컴퓨터에서 실행하기

이 폴더에서 터미널을 열고 Python 3가 설치되어 있다면 다음을 실행합니다.

```bash
python3 -m http.server 8000
```

Windows에서는 `py -m http.server 8000`도 사용할 수 있습니다. 브라우저에서 http://localhost:8000 을 엽니다. `index.html`을 더블클릭하는 `file://` 방식은 JavaScript 모듈 보안 정책 때문에 사용할 수 없습니다.

## 들어 있는 기능

- 우사기가 나무 팻말을 든 첫 화면과 테스트 시작 버튼
- 일상의 한 장면처럼 이어지는 20문항, 문항당 4개 선택지
- 굵은 선과 단순한 색으로 제작한 풍경 이미지 선택 문항 1개
- 선택 후 `다음 질문 (n/20)` 버튼을 눌러 이동
- `이전 질문`으로 돌아가 수정하고, 이후 답변도 그대로 유지
- 이 브라우저에 답변을 저장해 이어서 진행
- 네 장면 전환, 선택 반응, 편지 열기, 캐릭터 등장 모션
- 20명 결과 이미지, 성격 설명, 장점, 조언, 함께할 친구
- 친구의 결과와 궁합 비교, 결과·초대 링크 공유
- 1080 × 1440 PNG·JPG 결과 카드 저장 및 지원 브라우저의 이미지 공유
- 20명 캐릭터 도감, 출처 안내, 저장된 답변 삭제
- 키보드 접근, 선택 상태 안내, 기기의 동작 줄이기 설정 반영

## 20문항을 유지한 이유와 판정 방식

가볍게 즐기는 캐릭터 매칭이라는 목적에 맞춰 20문항·4지선다를 유지했습니다. 문항 수를 늘리기보다 캐릭터별 선택 패턴이 겹치지 않게 구성했습니다. 취향 이미지 하나로 성격이 결정되지 않도록 이미지 문항의 비중은 일반 문항의 절반입니다.

`data.js`의 캐릭터별 20개 응답 기준과 사용자의 선택이 일치할 때 점수를 더합니다. 일반 문항은 1점, 이미지 문항은 0.5점으로 총 19.5점입니다. 동점에서는 답변에서 얻은 다정함·호기심·표현력·꾸준함·행동력·자기 페이스의 여섯 신호를 비교합니다. 이 비교까지 같은 경우 캐릭터 ID 순으로 일관되게 정합니다.

가장 비슷한 두 기준도 이미지 문항을 제외하고 최소 5개 답이 다릅니다. 각 기준에서 답 하나를 바꾼 1,200개 사례에서도 해당 캐릭터가 유지됐고, 50,000개 가상 응답에서 20명 모두 결과로 나왔습니다. 이는 **코드의 구분 동작을 확인한 결과이며 사람 대상 심리 검사의 타당도나 정확도를 뜻하지 않습니다.** 성격 문구와 궁합은 공식 심리 유형이 아닌 팬 해석입니다.

자세한 검사 결과는 `docs/validation.json`, 테스트 코드는 `tests/engine.test.mjs`에 있습니다. Node.js가 설치된 환경에서 실행할 수 있습니다.

```bash
node tests/engine.test.mjs
node tests/share.test.mjs
node tests/personalization.test.mjs
```

## 수정할 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 기본 화면 틀, 제목·설명·미리보기 메타 태그 |
| `style.css` | 모바일 레이아웃, 색, 서체, 모션 |
| `data.js` | 질문·선택지·캐릭터 설명·선택 기준·궁합 친구 |
| `engine.js` | 결과 계산, 답변 저장, 이전·다음 이동 |
| `app.js` | 화면 전환, 공유 선택창, 이미지 다운로드 |
| `personalization.js` | 이름 저장, 결과 문구, 링크·이미지 공유 데이터 |
| `details.js` | 20명 캐릭터의 추가 성격 설명 |
| `relationships.js` | 친구 조합별 문구, 잘 안 맞는 친구와 이유 |
| `card.js` | 이름과 설명을 담은 PNG·JPG 카드 디자인 및 이미지 인코딩 |
| `sharing.js` | 플랫폼 목록, 파일명, 기본 앱 공유 및 지원 여부 처리 |
| `korean.js` | 받침에 맞는 한국어 조사 처리 |
| `assets/` | 캐릭터·풍경 이미지, 폰트, 미리보기 표지 |
| `assets/assets-manifest.json` | 원본 캐릭터 이미지의 공식 출처 |

답변 구조를 바꿀 때는 `data.js`의 `VERSION`도 올리면 이전 버전 답변을 다시 불러오지 않습니다. 이 버전은 20문항에 맞춰 화면과 진행 로직이 구성되어 있습니다. 문항 수 자체를 바꾸려면 해당 상수도 함께 수정해야 합니다.

## 이미지·폰트

캐릭터 원본은 공식 애니메이션·영화·굿즈 자료에서 가져왔습니다. 캐릭터와 관련 이미지의 권리는 원저작권자에게 있으며, 이 패키지는 해당 이미지에 별도의 이용허락을 부여하지 않습니다. 출처는 앱 하단과 `assets/assets-manifest.json`에 기록했습니다.

우사기 팻말과 네 장의 풍경은 AI로 제작한 이미지입니다. Jua와 Gowun Dodum 폰트는 동봉된 `OFL-jua.txt`, `OFL-gowun.txt`에 따라 사용합니다. 웹폰트는 파일 크기를 줄이기 위해 현재 문구에 맞춰 서브셋되었습니다. 문구에 새로운 글자가 들어가면 시스템 한글 폰트가 보충할 수 있습니다.

## 확인된 범위

문항·판정·답변 수정 및 복원·20명 결과 도달·정적 파일 연결을 검사했고, 20명 × 이름 2종으로 카드 40장을 렌더링하고 PNG·JPG 80개 파일의 실제 형식·크기·글자 영역·카드 내 링크 제거를 확인했습니다. 공유 버튼이 플랫폼 선택창을 열고, 취소 시 자동 복사하지 않는 동작도 코드 테스트로 확인했습니다. 실제 iOS/Android 브라우저에서의 터치·다운로드·네이티브 공유는 별도 확인이 남아 있습니다. HTTPS 환경에서 지원되는 네이티브 공유를 사용하며, 지원하지 않으면 플랫폼별 안내와 명시적인 링크 복사·PNG/JPG 저장 버튼을 표시합니다.

이름과 답변은 현재 브라우저의 로컬 저장소에만 저장됩니다. 링크 공유에는 이름이나 개별 답변을 넣지 않습니다. 카드에는 등록한 이름이 포함되므로 공유 전에 카드 미리보기에서 확인할 수 있습니다. 별도의 방문 통계나 계정 기능은 없습니다.
